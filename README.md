## 主动去AI味提示词 v9

明确要求自然化、模板表达处理和句式重构，按强度允许短语/句法/段落节奏调整。
同时提供局部建议和实际模型绝对系数最大的前10个语言学特征（含正负号及当前贡献），
不把系数直接当成人类目标；保留事实、否定、重要条件和确定程度。
同一次编辑请求输出简短建议与正文两个区块；建议存入记录，不混入成稿或最终差异卡片。
未输出建议区块时兼容纯正文；只输出建议没有正文视为未完成。仅空白变化不算成功编辑。
审查采用上下文命题等价标准，允许正常隐喻、句式重构和轻微修辞变化；不放松关键事实约束。
仍最多3次编辑，快速模型为默认，R1条件升级；实际效果需在新任务中评估。

## 最终修改记录

创作端修改记录只对照提交时原文与最终交付稿，不展示轮次、候选、审查意见或模型特征。
对照卡片与实际差异项分别计数；卡片说明来自真实文字/标点/格式变化，不编造修改动机。
差异保留精确字符位置和原始片段，可按 changes 重建最终全文；空白格式也纳入记录。
常见英文缩写保持上下文，拆并句显示完整句组，能识别的完整移位合并展示。
复杂语义移句可能仍显示为对应删除/新增，但原始差异保持完整，不声称自动语义对齐完美。
旧任务刷新时重新计算最终差异，无需重新调用模型。

## 五类局部建议 v8.1

最多5个不同类别的编辑重点；按当前正向局部贡献排序，同类特征合并而非重复占名额。
每项包括模型权重依据、原文quote及字符位置、可选编辑操作和保真约束。
定位是规则选取的检查线索，不是句级归因；无对应线索则跳过，不强凑5项。
快速模型和R1都会收到这些建议；每轮计划和各目标特征的实际变化保存到任务记录。
不增加模型请求，不改变分类器参数、三轮上限或语义验收规则。

## 自然表达优先 v8（新任务默认）

固定 LangGraph 工作流：本地诊断 → 一次直接编辑正文 → 本地评分/规则检查 → 独立语义审查。
不再让模型决定评分工具调度或输出 JSON 编辑动作。最多3次修改，保真通过且P(AI)<34%即提前停止。
自然表达、目标语域和原意优先；最多3条可选局部编辑建议，不把整篇文稿重塑成分类器模板。
快速模型默认 DEEPSEEK_FAST_MODEL=deepseek-chat，并明确关闭 thinking；第一轮始终快速。
深度强度3从第二轮起可用R1；任何强度出现语义问题，后续修复和审查可升级R1。
普通强度1/2且没有语义问题时持续用快速模型，不因单纯分数高自动升级。
最多3轮后，有通过保真的改稿即交付；分类分数独立报告，不要求相对原稿下降或低于阈值。
通过保真的多份改稿之间以较低分数作为保留策略；没有合格改稿则回退原文。
旧任务恢复仍走旧版本；新任务payload保存workflow_version=v8，避免检查点不兼容。
每次调用记录模型路由、模型ID、耗时和token。短连接测试不能作为全文任务延迟保证。

## 权重驱动动态计划 v7

使用实际融合 LR 的语言学系数、训练均值/尺度、当前标准化值与局部贡献。
每轮本地选择最多3个正向贡献项；方向基于系数符号，而非仅按权重绝对值排序。
提示词提供特征族编辑策略、长句/重复词证据和上一轮恶化项，禁止机械同义词替换或人为重复。
示例句不是句级归因；数值方向只代表其他特征不变时的线性效应，不承诺实际编辑收益。
每轮 round_records 保存 editing_plan 和 plan_evaluation，包括目标特征贡献变化、三类特征总贡献变化。
整体分数和语义检查继续决定是否接受，保留负向有效贡献；不放宽阈值，不修改论文模型。
计划生成不请求模型；实际改写质量改善仍需真实文本任务验证。

## 效率优化 v6

生产工作流开启 eager_candidates：评分工具收到新的完整候选稿即提交独立语义验证，
无需再由模型复制全文到 finish 动作，评分结果直接复用。
每轮最多2次工具调用，禁止隐藏的无限候选搜索。总预算仍为60000软token，不盲目增加。
usage_log 保存每次编辑、格式修复和语义审查的供应商 token 统计及结束原因，随任务导出。
最终一次完整请求可能越过软预算；统计包含上下文输入和推理输出，不能当作正文长度。

## 协议稳定性 v5

支持说明文字/代码围栏包裹的单个 JSON；拒绝多个 JSON、空输出和错误顶层类型。
工具参数严格按类型验证，提示词明确禁止把 text 包装成 title/type 等元数据对象。
生产编辑输出格式错误时，最多发起一次同模型格式修复请求；不携带整份工作流历史。
空输出、截断输出和已耗尽预算不进行格式修复。修复不允许补写正文，仍需通过全部校验。
两次不可恢复协议错误停止；修复 token 计入总预算，日志记录格式修复事件。
运行 `check_protocol.py` 可做两次短请求的基本协议验证，会产生模型费用；不是长文质量评估。

## 评分反馈循环 v3

每轮候选稿先计算论文分数，再独立检查规则和语义；只有保真通过且概率低于历史最佳值才接受。
原稿为回退基线，不把语义合格但分数上涨的改稿当作成功结果。
给 R1 的反馈包含候选概率、最佳概率、语言学贡献增加项和当前正向贡献项。
只在分数有下降、低于论文分类阈值且保真通过时标记 completed。
连续两轮相对最佳值没有至少 0.005（0.5 个百分点）的改善、达到5轮、12次决策或60000软token预算时停止。
这些预算和耐心参数是工程设置，不是论文验证结论。阈值是分类目标，不代表写作质量保证。
停止未达目标显示 needs_review；返回最佳合格候选，没有则返回原稿。
每轮被拒候选仍保存在 round_records 与任务导出中，可复查评分上涨原因。

## JSON 代理协议 v2

工具和结束动作严格区分；未知字段、重复调用和错误动作会反馈给 R1 修正。
工具异常作为错误观察返回，不冒充成功结果；私有异常内容不会放入工具反馈。
保留每轮草稿、论文评分、修改对照和独立审查。
页面“导出任务记录”下载完整任务与工具观察，不包含私有思考内容或密钥。
已完成任务无需重新调用模型；新代理逻辑需重启后端后对新任务生效。

## 当前论文模型接入

唯一方法来源为 `Classifier_ACL_Step1_to_Step5_Complete (1).ipynb`。
65 维特征函数从该 notebook 原样提取；运行时清理不可见字符、标点前空白和连续空白。
StandardScaler 后按 ±5 截断，再按训练索引保留 43 维，与 4000 词级和 2000 字符级 TF-IDF 加权融合。
使用提供的 VIF-pruned fusion LR，验证集锁定阈值为 0.34。
`models/paper_bundle.joblib` 仅包含推理对象，不含训练文本或大矩阵。
32 条缓存特征的预测对齐结果见 `models/import_report.json`；这不等同于原始文本端到端复现。
训练时的 spaCy/textstat/wordfreq 精确版本没有随文件提供，原文提取数值仍需后续对齐。
输入少于 80 或超过 1500 英文词时不输出论文概率，不静默截断。
评分是论文分类器输出，与语义质量检查分开；不把分类阈值擅自当作改写验收条件。
本地分析接口：`POST /api/analyze`，请求体 `{"text":"英文文本"}`，无需模型密钥。

保留原有创作页面，后端采用 FastAPI、LangChain 工具及 LangGraph 状态图。
原始桌面项目未修改。这是本地单用户版本，不应直接暴露到公网。

## 启动

1. 将 `.env.example` 复制为 `.env`，填写 `DEEPSEEK_API_KEY`。
2. 确认 `DEEPSEEK_BASE_URL` 与 `DEEPSEEK_MODEL` 对应你的 R1 部署。
3. 在项目目录执行 `powershell -ExecutionPolicy Bypass -File .\start.ps1`。
4. 浏览器打开 http://127.0.0.1:8000 。不要直接双击 HTML。

默认模型 ID 为 `deepseek-reasoner`，不会自动切换到其他模型。模型服务商的别名可能变更；
若需要严格的原版 R1 权重，请使用明确提供该版本的兼容端点并填入其真实模型 ID。
当前官方文档列出的产品与旧 R1 名称不同，因此尚未声称默认端点仍提供原版 R1。

## 架构

LangGraph: prepare → editor → tools → editor → verify → editor / END。

R1 通过 JSON 文本动作选择 LangChain `@tool` 工具，由图执行白名单分发。
这是真正的模型选工具循环，不依赖 R1 原生 function calling，也不伪装成 `create_agent`。
工具包括文风统计、保护项提取、保护检查、实际差异对比。
独立语义审查使用同一模型的新请求；这是独立审查步骤，不代表独立模型证据。

最多 12 次编辑决策、3 轮检查，软 token 上限 60000（完整调用可能跨过上限，随后停止）。
单次调用超时 120 秒并允许一次重试。未通过检查时显示 `needs_review`，不会标记合格。
实际修改由差异算法生成，不展示模型私有思考过程，不提供 AI 作者概率或绝对保真承诺。

## 持久化与恢复

任务与 LangGraph 检查点保存在 `data/` 下的 SQLite 文件。
浏览器保存最近任务 ID，刷新后继续查看；服务重启会把未完成任务标记为 interrupted。
点击“恢复中断任务”从已保存检查点继续。失败步骤可能重复发起模型请求并产生费用。
同时允许两个本地任务，无公网鉴权；上线前需补账号、用户隔离和部署级限流。
原稿、工具结果和模型响应属于敏感资料，会保存在本机检查点；不启用远程 tracing。
关闭服务后可自行删除 `data/` 清除任务。字体与 Tailwind 样式仍依赖原页面的 CDN。
